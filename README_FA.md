# املاک اتحاد — پروژه اندروید

این پروژه، نسخه اولیه قابل ویرایش نرم‌افزار اندرویدی «املاک اتحاد» است.

## امکانات
- محاسبه کمیسیون خرید و فروش بر اساس حداقل مبلغ، درصد حداقل، درصد مبلغ مازاد و ارزش افزوده.
- محاسبه کمیسیون رهن و اجاره بر اساس مبلغ رهن و اجاره ماهانه.
- محاسبه سهم تمدید موجر و مستأجر.
- تنظیمات قابل تغییر و ذخیره‌شونده در حافظه داخلی برنامه (SharedPreferences).
- نشان ساده سرمه‌ای و طلایی با طرح ساختمان.

## مقادیر پیش‌فرض برگرفته از فایل اکسل
- ارزش افزوده: ۱۰٪
- حداقل مبلغ معامله: ۱٬۲۰۰٬۰۰۰٬۰۰۰ تومان
- درصد کمیسیون تا حداقل مبلغ: ۱٪
- درصد کمیسیون مبلغ مازاد: ۰٫۲۵٪
- درصد کمیسیون رهن: ۱٪
- ضریب اجاره ماهانه: ۱/۳
- ضریب تمدید موجر: ۱/۲
- ضریب تمدید مستأجر: ۱/۴

## ساخت APK
1. پوشه پروژه را در Android Studio باز کنید.
2. اجازه دهید Gradle Sync کامل شود (به اینترنت برای دریافت ابزارهای Gradle/Android نیاز است).
3. از منوی Build گزینه Build APK(s) را انتخاب کنید.
4. فایل APK معمولاً در `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

## نکته مهم
این نسخه اولیه از فرمول‌های فایل اکسل و مقادیر پیش‌فرض استخراج‌شده استفاده می‌کند. پیش از استفاده مالی رسمی، محاسبات را با چند نمونه واقعی و مقررات جاری اتحادیه/مالیات تطبیق دهید. مقادیر و ضرایب از بخش تنظیمات قابل تغییر هستند.
